# 公开物理与离散契约

时间 day、空间 m、浓度 g/m³。移动域储存 W=C+Q*b*C/(1+b*C)，非移动域储存 β*C_im。方程为 dW/dt=D∇²C-div(v*C)-λC-κ(C-C_im)+q/φ；β*dC_im/dt=κ(C-C_im)-β*λ*C_im。Q 是每移动水体积的吸附容量；b 是 Langmuir 亲和系数。其余符号由 scene.json 和 source_bounds.json 给出。

每个源为均匀长方体，空间分配用真实体积与网格单元的重叠比例。释放区间分为三个等长片段，各片段总质量率分别为 rate0/1/2。注入使用片段与时间步的精确重叠比例。边界与原协议相同：上游零浓度；下游与横向零梯度。使用一阶迎风、中心扩散和公开稳定时间步。显式更新 W 与 β*C_im 后，解析求解 Langmuir 储存关系正根取得新的 C，保持交换项的质量守恒。

calibration_source 是已知注入实验；contaminant 是共享同一水文/吸附参数的两个未知污染源。观测位于固定监测格点，非检出记录为区间 [0,0.0003)，不能当作精确零。数据来自本项目的合成双域模拟，未运行 MODFLOW。public/simulator.py 提供完整可调用的公开前向模型，不要求重写它。

## 空间介质与水力实验（r2）

介质 K=0.23*exp(trilinear(logK)) m/day，logK 为公开的 7×4×3 控制网格，共84个待反演系数。稳态水头满足 div(K grad h)=0；两个公开水力实验分别在 x 或 y 两侧施加 scene.json 的已知水头，其余边界无流。单元面通量采用谐均导水系数，Dirichlet 边界到单元中心距离为半个单元。水头与总入口流量观测见 hydraulic_observations.csv；ix=-1 行是总流量，单位 m³/day。观测噪声 sd 明示。

输运使用 x 方向水力实验得到的三维 Darcy 面通量，再乘 velocity_scale/porosity 得到孔隙流速。一阶守恒迎风、各向扩散、Langmuir储存和移动/非移动交换共同决定浓度。公开 hydrology.py 与 simulator.py 给出完整实现。稳定时间步为0.5/ceil(0.5*max_rate/0.8)，至少一段；所有采样时刻均为0.5的整数倍。导水场、介质参数与两污染源须联合推断，总113参数。水力观测只用于反演，不与浓度误差混用单位计分。固定反馈及审计仍按原浓度公式给分。
