# Source and decision

- Official repository: https://github.com/openapi-generators/openapi-python-client . Full revision: `0a283fe21eeaa23046faf622d4ff4b2c826d2edb`; MIT license in bundled source. Official codeload tarball is archived and SHA256-pinned in `authoring/build-manifest.json`. The full repository is retained, including the real parser, templates, generated-client behavior tests and CLI; this is not a replacement miniature generator.
- Target behavior is the SDK application profile in `instruction.md`, informed by OAS 3.1.1 https://spec.openapis.org/oas/v3.1.1.html and JSON Schema annotation semantics https://json-schema.org/understanding-json-schema/reference/annotations . Issue leads #1328, #1392, #1428 and #1435 were research inputs; their authors' claims are not used as independent expected-output oracles. No issue attachment is redistributed. All new schemas/assertions are author-created with hand-specified attribute, missing-value and wire-byte expectations.
- Implementation evidence: `parser/properties/model_property.py::_process_properties` traverses only one inline `allOf` layer; `property_from_data` unwraps a single-reference composition before preserving siblings; `list_property.py::build` rejects a bare array; the new reference integrates `parser/composition.py` at `GeneratorData.from_dict`. Existing generator and SDK templates execute after lowering.
- Strong public starting point: the complete fixed upstream generator. Current frozen workload scores **0/6**, not an artificial empty implementation. Existing native tests remain public. A schema preprocessing pass is a real cheap route: the reference uses it successfully and therefore **does not establish six-hour difficulty**. Passing all six groups is attainable with roughly 130 lines of integrated lowering plus existing runtime machinery.
- Two paths remaining after two hours are hypotheses, not observed model behavior: (a) broaden supported intersections to conflicting constraints, recursive references and branch-local closure without violating JSON Schema semantics; (b) add first-class typed union selection, discriminators, diagnostic paths and compatibility for complex endpoints. These are outside the current pilot contract and cannot be counted as current task difficulty.
- Cheapest falsification: run starter and reference, targeted semantic mutations, then upstream generated-code execution tests. Actual evidence is in `authoring/evidence`; reference 1.0, starter/empty 0.0, two partial implementations 5/6, native tests 321 passed/4 skipped and generated execution 80 passed. No measured model trajectory, no runtime oracle/Harbor result.
- Decision: **build_pilot** for end-to-end construction evidence; **reject_current_profile_for_long_horizon** for the current six-hour candidate. The cheap general normalizer exhausts the present profile. Do not count this as an accepted EdgeBench task.
