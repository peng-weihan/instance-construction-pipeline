# Preserve composed schema behavior through generated Python SDKs

Modify the complete `openapi-python-client` 0.29.1 source at `/home/workspace/openapi_composition/submission` (upstream commit `0a283fe21eeaa23046faf622d4ff4b2c826d2edb`). Submit the source tree, including the `openapi_python_client` package, templates and project metadata. The judge invokes `python -m openapi_python_client generate --path spec.json --meta none --output-path <package-directory>` in this tree, then imports and executes the resulting SDK in a fresh subprocess. Implement the generator; the input schemas and output directory vary.

Support the following coherent OpenAPI 3.1.1 SDK profile using the existing command and model/endpoint APIs:

1. Object `allOf` may contain local component references, inline objects, and nested `allOf`. Preserve every property and the union of all `required` lists. Sibling `properties`/`required` on the composing schema also contribute. Local references can be reused across fields and compositions.
2. An object intersection may contain a `oneOf` or `anyOf` of disjoint object branches. Preserve the common object fields in every branch; preserve typed generated model instances and each branch's fields during `from_dict`/`to_dict`. Branches in the evaluated profile are unambiguous because of required `const` tags or required disjoint fields. This task does not impose arbitrary first-match behavior on overlapping JSON Schema unions.
3. `type: array` without `items` in OpenAPI 3.1 means unrestricted elements. Support it as a required/optional model field and inside unions. Preserve nested JSON values, nulls, empty lists and strings when those are distinct union branches.
4. Keep optional wire fields as `UNSET` when absent. Preserve the existing SDK convention that a scalar `default` can supply a constructor default; parsing missing JSON fields must not manufacture a wire value. `default` is an annotation, not a general JSON Schema data mutation rule.
5. Models produced by these compositions must work as request and response bodies. Generated synchronous and asynchronous endpoint calls must send correct JSON bytes, method, URL and content type through httpx, and deserialize typed response objects.
6. A contradictory intersection of property primitive types (except integer intersect number, which is integer) must fail generation with a nonzero status and a diagnostic identifying the schema and property. Do not silently create a successful client that drops the conflicting property.

The profile uses local `#/components/schemas/...` references, open objects, integer/string/boolean/number/null primitives, scalar enums/const, homogeneous arrays and finite acyclic composition references. Recursive object properties may retain ordinary references, but recursive `allOf`, external references, cross-branch `unevaluatedProperties`, overlapping union validation, boolean schemas and arbitrary JSON Schema validation are outside this profile. Preserve existing generator behavior for ordinary models and endpoints. The complete upstream tests remain available for development.

Run from `submission` with `python -m openapi_python_client generate ...`; dependencies are installed offline. You may change parser, internal types, templates, CLI and tests and add Python modules. Use installed Python packages and ordinary shell tools; no network is available during solving or judging. No generated client or result cache replaces the generator source.

The score is `sum(passed group)/6`, bounded to [0,1], over fixed equally weighted groups: nested inheritance; intersection with union; bare arrays; sibling/reference/default behavior; synchronous/asynchronous HTTP client execution; conflicting-type diagnostics. A group requires every assertion in that group. Repeated cases do not increase a group's weight. Empty, syntax-invalid, timed-out or incorrect submissions receive their actual valid score, including zero. Judge infrastructure failures have `valid=false` and no reward. This is a local behavior pilot; six-hour difficulty and container acceptance have not been measured.
