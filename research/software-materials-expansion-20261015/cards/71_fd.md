# 71_fd fd 查找、筛选与批量执行的行为兼容实现

- 路线：M5；优先级：`scope_probe`。素材候选，未构题/构建/运行/校准。
- 固定源码：`sharkdp/fd@14dcd92fb76ca0ebc2e82671a275f67c790d25fc`；源码哈希/清单见 `../sources/71_fd/manifest.json`。
- 完整候选范围：完整限定工作流：多 root 目录遍历→ignore/隐藏/类型/regex 筛选→NUL/格式输出→占位符批量执行→退出码与副作用；不是单个 flag。
- 原题锚点：`git_rewrite_in_zig`；仅借难度机制，不承诺同等运行难度。
- 已有能力：现有 fd 以 ignore 并行遍历、批次 channel 和 exec job/batch 连接整个流程；输出可能从缓冲排序转为流式，不能全局假定排序。
- 拟议缺口：拟为其他实现方式建立上述工作流的兼容合同，不声称上游缺失；全部 fd 选项不是当前已锁定范围。

## 三类工作负载/工作流

- 嵌套 ignore/hidden/symlink 与多个 root
- 空格/换行/前导减号路径的 NUL 输出和 exec 占位符
- 批量大小/多命令/子命令失败的参数、退出码和文件副作用

- 最强正常基线：成熟 regex/ignore/walk/process 库和普通管道组合先试；合法工具/包装如能完成合同即否证难题，不在事后禁库或单加隐藏限制。
- 首探/否证：先做冻结上游完整旅程差分与最小合法组合；顺序按接口约定规范化，同时保留逐次 argv/副作用；若薄封装就足够，换范围/项目。
- 正确性 oracle：冻结 fd+独立文件树清单；记录子进程 argv、stdout/stderr、exit 和写入文件；不强行比较非确定顺序；原生 exec tests 为种子，独立新 fixture。
- 后续结构假设 1：若正常库仍不足，统一字节路径/ignore precedence 与输出格式，跨 walk/filter/serializer 实现兼容。
- 后续结构假设 2：若进程组合仍不足，补齐 exec 占位符、参数上限 batching、输出隔离和失败聚合的统一语义。
- 离线：Rust 1.90/edition2024 与 Cargo.lock 依赖 vendor；测试使用的外部 helper 需固定离线版本。
- 许可观察：Cargo.toml 声明 MIT OR Apache-2.0，根两份许可已存，依赖另核。
- 平台风险：POSIX bytes/symlink 与 Windows 路径不同，先固定 Linux；ARM 构建/进程上限另验。
